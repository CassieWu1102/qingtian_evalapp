# 招标组织方案评估与优化系统

本应用是一个基于 Streamlit 搭建的 Web 应用，旨在帮助用户评估和优化招标组织方案。它利用大语言模型（支持 OpenAI 接口规范）对方案进行专业视角的分析，特别针对**科大讯飞“青天”大模型**等自动化评标系统进行适配和建议，以提高方案的中标率。

## ✨ 核心功能

1. **双文档对比分析**：支持同时上传【招标文件】和【招标组织方案】进行深度对比。
2. **多格式文档解析**：支持上传 `.pdf`, `.docx`, `.txt` 格式的招标方案文件。
3. **需求响应度检查**：严格对比招标文件，自动排查方案中的遗漏项、未响应项或矛盾点，防范废标风险。
4. **“青天”模型友好度分析**：评估方案中是否包含核心得分关键词，以及文档结构是否利于 AI 提取。
5. **具体修改建议**：提供详细的【修改前】与【修改后】对比示例。

## 🚀 快速开始

### 1. 安装依赖环境

请确保您已经安装了 Python (建议 3.8+)。在项目根目录下运行以下命令安装所需依赖：

```bash
pip install -r requirements.txt
```

### 3. 配置模型接口 (后端设置)

为了保护 API Key 等敏感信息，系统采用后端环境变量的方式进行配置。前端用户无需也无法输入 API 密钥。

1. 在项目根目录下，复制 `.env.example` 文件并重命名为 `.env`：
   ```bash
   cp .env.example .env
   ```
2. 编辑 `.env` 文件，填入您的模型参数。如果您不知道如何获取这些参数，请查阅详细的 [API Key 获取与配置指南](API_KEY_GUIDE.md)。
   ```env
   # .env 示例
   API_KEY="sk-xxxxxxxxxxxxxxxx"
   BASE_URL="https://api.openai.com/v1"
   MODEL_NAME="gpt-4o"
   ```

*(注意：请确保* *`.env`* *文件已被加入* *`.gitignore`，不要将其提交到公开的代码仓库中！)*

### 4. 启动应用

在终端中运行以下命令启动 Streamlit 服务：

```bash
streamlit run app.py
```

## 📌 注意事项

由于“青天”大模型评标系统对信息的结构化和关键词极其敏感，请务必根据 AI 给出的修改建议，优化方案的排版（如多用清晰的层级列表）和专业术语表述。
